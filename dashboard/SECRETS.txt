================================================================================
EnviroNode-WL55 dashboard - SECRETS you must provide
================================================================================
The app reads these five settings. Order of precedence:
  1. the sidebar fields (typed at runtime - nothing is stored)
  2. Streamlit secrets (.streamlit/secrets.toml locally, or Space Secrets on HF)
  3. environment variables of the same name

  TTN_API_KEY     (SECRET) The Things Network API key, full "NNSXS...." string.
                           Rights needed: "Read application traffic (uplink)",
                           "Write downlink application traffic", "View devices".
                           Create at: TTN console -> your application -> API keys.
  TTN_APP_ID               Application ID.        e.g.  geoenvironode
  TTN_DEVICE_ID            End-device ID.         e.g.  envnode-01
  TTN_REGION               Cluster.               e.g.  au1   (au1 | eu1 | nam1)
  TTN_GATEWAY_ID  (opt.)   Gateway ID for the Status panel.  e.g. geoenvirosense01

--------------------------------------------------------------------------------
PREREQUISITE ON TTN (once): enable the Storage integration so history works.
  TTN console -> your application -> Integrations -> Storage Integration -> Activate.
  The uplink formatter (docs/PAYLOAD.md) should also be installed so decoded
  fields appear; if it is not, this app decodes the raw bytes itself.

--------------------------------------------------------------------------------
LOCAL (Windows):
  1. Run install.bat
  2. copy  .streamlit\secrets.toml.example  ->  .streamlit\secrets.toml
     and paste your TTN_API_KEY (and adjust the others if needed).
  3. Run run.bat  ->  opens http://localhost:8501
  (Or skip step 2 and just paste the key into the sidebar each time.)

--------------------------------------------------------------------------------
HUGGING FACE SPACE:
  1. Create a new Space -> SDK: Streamlit.
  2. Upload app.py and requirements.txt (and README.md for the Space header).
  3. Space -> Settings -> "Variables and secrets":
       Add SECRET  named  TTN_API_KEY   = your NNSXS.... key
       Add VARIABLEs named TTN_APP_ID, TTN_DEVICE_ID, TTN_REGION, TTN_GATEWAY_ID
     (Use a Secret for the API key; the rest can be plain Variables.)
  4. The Space rebuilds and runs. Do NOT commit secrets.toml to the Space.

--------------------------------------------------------------------------------
SECURITY:
  * Never commit a real key. .gitignore already excludes .streamlit/secrets.toml.
  * A key with only view/read/write-downlink rights CANNOT change device
    settings or read your other applications - keep it that narrow.
  * If a key leaks, delete it in the TTN console (API keys -> Delete) and make
    a new one; the app has no other stored state.
